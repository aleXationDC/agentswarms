# aXtn Workbenches

aXtn Workbenches are versioned, task-oriented UI extensions that compose
existing AgentSwarms capabilities or a declared data contract. They do not
replace AgentSwarms agents, swarms, orchestration, approvals, pause/resume,
runtimes, or providers.

`registry.json` is the machine-readable index. Each Workbench directory has a
manifest and installation/removal notes. A Workbench is portable only with the
native capabilities and aXtn dependencies declared in its manifest.
